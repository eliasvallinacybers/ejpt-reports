# eJPT Reports

This repository contains my personal cybersecurity lab reports and notes created during my eJPT preparation.

These reports were written by me as a way to organize my learning process, document the methodology followed in each lab, and keep a structured record of the tools, commands, techniques, and reasoning used throughout the different sections of the eJPT path.

## Purpose

The purpose of this repository is to show my practical progress in cybersecurity and to keep evidence of the work I have completed manually during my training.

Each report focuses on understanding the process behind the techniques used, rather than simply collecting commands. The goal is to document what I have learned, how I approached each task, and why each step was performed.

## Contents

The reports cover different areas of penetration testing, including:

* Information gathering
* Footprinting and scanning
* Enumeration
* Vulnerability assessment
* System and host-based attacks
* Network-based attacks
* Exploitation
* Post-exploitation
* Web application security basics
